# Simple Interest Calculator

A simple calculator that calculates simple interest based on the principal amount, interest rate, and time period.

## Formula

Simple Interest = (Principal × Rate × Time) / 100

## Inputs

- Principal amount
- Rate of interest
- Time period

## Output

The calculator displays the calculated simple interest.

## Example

Principal = 1000  
Rate = 5%  
Time = 2 years  

Simple Interest = 100
